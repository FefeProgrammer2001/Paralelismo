# Programming with parallelism using threads and processes

### The ideia is use parallelism techniques to optimze classics algorithsm, such as sort algorithms, matrix multiplication, and others.

### How to compile code with Pthread:
    clang -Wall -Werror -Wextra -std=c23 -O3 -lpthread name.c -o a.out

### How to compile with POSIX process:
    clang -Wall -Werror -Wextra -std=c23 -O3 name.c -o a.out
### No need compilation flags with posix process <unistd.h>
